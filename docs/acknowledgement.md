# Acknowledgements

This resource is based on work originally done for the [Connected Interaction Kit](https://id-studiolab.github.io/Connected-Interaction-Kit/) at TU Delft by  [Adriaan Bernstein](https://bernstein.design), [Aadjan van der Helm](https://studiolab.ide.tudelft.nl/studiolab/vanderhelm/), and [Frederick Ueberschär](https://ueberschaer.design), with contributions from [Martin Havranek](https://www.tudelft.nl/staff/m.c.havranek/).

The foundational content for the DTI Summer School Workshop was created by [Adriaan Bernstein](https://bernstein.design). For the 2025 edition, Heinrich Kortsch authored the project idea pages for Part 2, incorporating visualizations by Adriaan Bernstein. The "Tiny Sorter" module for Part 3 is an adaptation of the original [Google Tiny Sorter project](https://experiments.withgoogle.com/tiny-sorter), reworked for the Pi Pico and documented for the DTI 2025 microcontroller workshop by Heinrich Kortsch.
